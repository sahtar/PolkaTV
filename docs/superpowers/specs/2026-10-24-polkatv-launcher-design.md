# PolkaTV («Полка») — домашний экран для Xiaomi TV в стиле Apple TV

Дата: 2026-10-24. Статус: дизайн согласован с пользователем, ждёт реализации.

## 1. Цель

Заменить стандартный главный экран Google TV на телевизоре Xiaomi MiTV-MOEU1 своим приложением-лаунчером «Полка»:
часы, виджет погоды для нескольких городов с подробностями, 4–6 плиток приложений по выбору пользователя,
служебные иконки (входы, уведомления, сеть, настройки), фон из фотографий заставки Xiaomi. Кнопка Home открывает «Полку».

## 2. Целевое устройство и ограничения

| Параметр | Значение |
|---|---|
| Модель | Xiaomi MiTV-MOEU1 (Google TV), MediaTek MT5896, 4 ядра |
| Android | 14 (API 34), armeabi-v7a |
| Память | 2.4 ГБ RAM, свободно после загрузки ~0.8–1.0 ГБ |
| Экран | Панель 4K, интерфейс Android рендерится в 1920×1080, density 320 |
| Локаль | ru-RU, 24-часовой формат по системе |
| Ввод | Только пульт (D-pad, OK, Back, Home, Menu). Сенсорного экрана нет |
| Доступ | ADB по сети 192.168.100.2:5555 (включён пользователем) |
| Текущий Home | com.google.android.tvlauncher/.MainActivity; PatchWall (com.mitv.tvhome.atv) установлен, вызывается своей кнопкой пульта |
| Сборка | macOS, Android Studio + SDK в ~/Library/Android/sdk, JDK 21 (JetBrains Runtime), Gradle wrapper |

Приложение пишется под это устройство. Другие ТВ не цель, но код не должен содержать ничего специфичного для Xiaomi, кроме раздела про входы.

## 3. Решения, согласованные с пользователем

1. Приложение становится домашним экраном (HOME), а не отдельной программой.
2. Макет «полка» как в tvOS: сверху часы и служебные иконки, посередине широкий виджет погоды, внизу ряд крупных плиток.
3. Фон: 24 фотографии из заставки Xiaomi MiDream (14 из текущей ротации с CDN Xiaomi + 10 запасных, зашитых в APK заставки), все 4K, сохранены в `design/wallpapers-src/`. Все 24 используются.
4. Стек: Kotlin, Jetpack Compose, Compose for TV. Один модуль `app`.
5. Решения, принятые исполнителем без вопросов: погода из Open-Meteo; интерфейс на русском с запасным английским; стартовые плитки YouTube, Кинопоиск, Иви, KION, Okko; название приложения «Полка», пакет `ru.polkatv.launcher`.

## 4. Пользовательский интерфейс

### 4.1 Главный экран

Три яруса сверху вниз, отступы от краёв экрана 4–5% (безопасная зона ТВ).

- **Шапка.** Слева часы `HH:mm` крупно (около 64 sp) и под ними дата словами («пятница, 24 октября»). Справа ряд из пяти круглых служебных иконок (п. 4.6).
- **Полка погоды.** Одна карточка на всю ширину, полупрозрачное размытое «стекло» (цвет 20/24/40 с альфой 0.45, рамка белая с альфой 0.18, радиус 24 dp). Содержимое в п. 4.4.
- **Ряд плиток.** 4–6 плиток приложений по выбору пользователя (по умолчанию 5) и за ними одна постоянная плитка «Все приложения» (полупрозрачная, иконка сетки, подпись). Все плитки 16:9, одинакового размера, радиус 16 dp; ширина подбирается так, чтобы ряд с 7 плитками помещался в безопасную зону.

### 4.2 Навигация пультом

- При запуске и при каждом возврате на главный экран фокус стоит на первой плитке приложений.
- Вверх: плитки → полка погоды → служебные иконки. Вниз: обратно. Влево/вправо: внутри текущего яруса. Фокус внутри яруса запоминается при переходах между ярусами.
- Плитка в фокусе масштабируется до 1.10 с белой рамкой 3 dp и тенью, анимация 150 мс. Иконка в фокусе становится белой с тёмным символом.
- OK на плитке запускает приложение через его leanback-интент. Долгое нажатие OK (или кнопка Menu) открывает меню плитки: «Заменить приложение», «Сдвинуть влево», «Сдвинуть вправо». Пустая плитка (приложение удалено) показывает подпись «Выбрать приложение», OK открывает выбор.
- Back на главном экране ничего не делает. Home из любого приложения возвращает на главный экран (стандартное поведение системы). Back на остальных экранах «Полки» возвращает на предыдущий.

### 4.3 Плитки приложений

- Источник списка: PackageManager, активности с категорией `LEANBACK_LAUNCHER`, плюс для полноты `LAUNCHER`, если у приложения нет leanback-активности. Исключается само приложение «Полка».
- Картинка плитки: баннер приложения (`android:banner`, 16:9), если он есть; иначе иконка приложения по центру на градиенте из двух доминирующих цветов иконки (Palette API). Подпись названием приложения показывается только для варианта с иконкой.
- При установке/удалении приложений (`ACTION_PACKAGE_ADDED/REMOVED/CHANGED`) список обновляется без перезапуска.

### 4.4 Виджет погоды

Данные одного города за раз. Содержимое карточки:

- Название города, при неоднозначности регион («Москва», «Ростов-на-Дону, Ростовская область»).
- Описание погоды по коду WMO на русском («облачно, небольшой дождь»), иконка состояния с учётом дня/ночи.
- Крупная текущая температура (около 72 sp, знак, без десятых).
- Строка подробностей: ощущается как, ветер (м/с и направление буквами: С, СВ, В, …), влажность %, давление в мм рт. ст., вероятность осадков % на ближайший час.
- Почасовой прогноз на следующие 8 часов: время, иконка, температура.
- Точки-индикаторы городов под карточкой (активный город ярче).
- Пометка «обновлено N мин назад», если данным больше 60 минут или сети нет.

Взаимодействие:

- Влево/вправо на карточке листают города (от 1 до 6). Если город один, стрелки ничего не делают.
- OK открывает экран подробного прогноза: текущие данные, почасовой прогноз на 24 часа (горизонтальный список), прогноз на 7 дней (мин/макс, иконка, вероятность осадков), восход и закат.
- Долгое нажатие OK: «Добавить город», «Удалить этот город», «Сделать первым».
- Добавление города: поле ввода с экранной клавиатурой, после 2+ символов запрос к геокодингу Open-Meteo (`language=ru`), список до 8 подсказок с названием, регионом и страной; OK добавляет.
- Если городов нет (первый запуск): карточка показывает «Добавьте город, чтобы видеть погоду» и OK открывает добавление.

### 4.5 Фон

- 24 фотографии, заранее уменьшенные до 1920×1080 (WebP, качество ~80) и упакованные в `assets/wallpapers/`. Порядок показа: случайная перестановка при каждом запуске, затем по кругу.
- Смена каждые 5 минут по умолчанию (настраивается: 1, 5, 15, 30 минут, выключено). Переход плавным растворением 1500 мс.
- Поверх фото затемняющий градиент: сверху чёрный с альфой 0.35, середина 0.20, низ 0.65 (режим «среднее»); режим «лёгкое» вдвое слабее.
- В памяти не более двух декодированных кадров (текущий и следующий, около 8 МБ каждый при 1080p ARGB). Декодирование в фоне с `inSampleSize` под размер экрана.

### 4.6 Служебные иконки (слева направо)

| Иконка | Действие |
|---|---|
| Входы | Своё диалоговое окно: список входов из `TvInputManager` (HDMI 1–3, антенна/кабель), для каждого состояние подключения. Выбор переключает вход (п. 6.2) |
| Уведомления | Системная панель: интент `com.android.tv.NOTIFICATIONS_PANEL` (на этом ТВ его обрабатывает com.google.android.tvrecommendations) |
| Сеть | Иконка отражает состояние (Wi-Fi с уровнем / кабель / нет сети). OK открывает `com.android.tv.settings/.connectivity.NetworkActivity`, запасной вариант `android.settings.WIFI_SETTINGS` |
| Настройки ТВ | `android.settings.SETTINGS` |
| Настройки «Полки» | Экран настроек приложения (п. 4.7) |

### 4.7 Экран «Все приложения»

Сетка 6 колонок, плитки такого же вида, что и на главном, подписи под плитками, сортировка по названию. OK запускает приложение. Долгое нажатие: «Добавить на главный экран» (в первую пустую плитку или заменить выбранную через подменю), «Информация о приложении» (системный экран приложения).

### 4.8 Настройки «Полки»

Список разделов в стиле настроек Android TV (левая колонка разделов, правая — содержимое):

- **Плитки.** Количество слотов 4–6. Для каждого слота выбор приложения из списка установленных или «пусто».
- **Города.** Список с порядком, добавить, удалить, сдвинуть выше/ниже.
- **Фон.** Интервал смены, затемнение (лёгкое/среднее).
- **Часы и дата.** Формат 12/24 ч: «как в системе» (по умолчанию) или принудительно. Показывать дату: да/нет.
- **О приложении.** Версия, кнопка «Сделать домашним экраном» с подсказкой (команда ADB), кнопка «Вернуть Google TV» с подсказкой.

## 5. Архитектура

Один Gradle-модуль `app`, пакет `ru.polkatv.launcher`. Слои по папкам, зависимости направлены сверху вниз: `ui` → `domain`-модели и репозитории → платформенные источники.

```
ru.polkatv.launcher
├─ MainActivity.kt            HOME-активность, одна на всё приложение, навигация Compose Navigation
├─ ui/                        Compose-экраны и компоненты
│  ├─ home/                   HomeScreen, Header, WeatherShelf, AppRow, TileMenu
│  ├─ apps/                   AllAppsScreen
│  ├─ weather/                WeatherDetailScreen, AddCityDialog
│  ├─ settings/               SettingsScreen и подэкраны
│  ├─ inputs/                 InputsDialog
│  └─ theme/                  цвета, типографика, размеры (всё в dp/sp под 1080p)
├─ apps/                      AppsRepository (PackageManager, баннеры, запуск, слушатель пакетов)
├─ weather/                   OpenMeteoApi, WeatherRepository, WeatherCache, WmoCodes, Units
├─ wallpaper/                 WallpaperController (список, таймер, декодирование, предзагрузка)
├─ settings/                  SettingsRepository на DataStore Preferences, модели Tile, City, Prefs
└─ system/                    SystemActions (интенты системных экранов), InputsController (TvInputManager), NetworkStatus
```

- **Состояние.** Один `HomeViewModel` собирает `StateFlow<HomeState>` из репозиториев: плитки с разрешёнными приложениями, текущий город и прогноз, состояние сети, текущий кадр фона. Экраны настроек и погоды имеют свои ViewModel.
- **Хранение.** DataStore Preferences для настроек (JSON-строки через kotlinx.serialization для списков). Кэш погоды: файл `files/weather/<lat>_<lon>.json` с временем получения. Room не используется.
- **Сеть.** OkHttp + kotlinx.serialization. Таймауты 10 с. Один повтор при сетевой ошибке.
- **Фон.** Таймер на корутине, живёт пока активность в `STARTED`. При уходе в фон таймер останавливается, следующий кадр не декодируется.
- **Библиотеки.** Compose BOM, `androidx.tv:tv-material`, `androidx.tv:tv-foundation`, Navigation Compose, Lifecycle ViewModel Compose, DataStore Preferences, OkHttp, kotlinx.serialization, kotlinx.coroutines, Palette. Без Hilt (ручная сборка зависимостей в `AppContainer`), без аналитики.

### 5.1 Манифест

- `MainActivity`: `launchMode="singleTask"`, `excludeFromRecents="true"`, `stateNotNeeded="true"`, `screenOrientation="landscape"`, `configChanges` для locale/uiMode.
- Фильтры: `MAIN + HOME + DEFAULT` (чтобы быть домашним экраном) и `MAIN + LEANBACK_LAUNCHER` (чтобы запускаться из Google TV до переключения). `android:banner` 320×180.
- `uses-feature android.software.leanback required=true`, `android.hardware.touchscreen required=false`.
- Разрешения: `INTERNET`, `ACCESS_NETWORK_STATE`, `QUERY_ALL_PACKAGES` (нужно для списка приложений; приложение не публикуется в Play).

### 5.2 Ресурсы

- Строки: `values/strings.xml` (русский, основной) и `values-en/strings.xml`.
- Иконки погоды и служебные: векторные drawable, монохромные, цвет через tint.
- `design/wallpapers-src/` — 24 оригинала 4K (не в APK). `tools/prepare_wallpapers.sh` уменьшает их в `app/src/main/assets/wallpapers/wp_01.webp … wp_24.webp` (1920×1080).

## 6. Системная интеграция

### 6.1 Домашний экран

- Назначение: `adb shell cmd package set-home-activity ru.polkatv.launcher/.MainActivity`. Проверка: `cmd package resolve-activity -a android.intent.action.MAIN -c android.intent.category.HOME`.
- Откат: `adb shell cmd package set-home-activity com.google.android.tvlauncher/.MainActivity`.
- Google TV и PatchWall не отключаются и не удаляются. Кнопка PatchWall на пульте продолжает открывать PatchWall.
- Приёмка: после перезагрузки ТВ кнопка Home открывает «Полку». Если прошивка возвращает Google TV, добавляется приёмник `BOOT_COMPLETED`, который запускает `MainActivity` (запасной механизм, включается только по результату проверки).

### 6.2 Входы

- Список: `TvInputManager.getTvInputList()`, фильтр `isPassthroughInput()`; состояние `getInputState(id)` (подключён / нет сигнала / отключён). На этом ТВ: `com.mediatek.tis/.HdmiInputService/HW2..HW4` (HDMI 1–3), `com.mediatek.tis/.AnalogInputService/HW1` (ATV), `com.mediatek.dtv.tvinput.dvbtuner/.DvbTvInputService/HW0`.
- Переключение, вариант 1: `Intent(ACTION_VIEW, TvContract.buildChannelUriForPassthroughInput(inputId))` с `setPackage("com.mitv.livetv")`.
- Вариант 2, если первый не работает на этой прошивке: тот же интент без указания пакета.
- Вариант 3: запуск Live TV обычным leanback-интентом, пользователь выбирает вход внутри него.
- Рабочий вариант определяется на этапе реализации на реальном ТВ и фиксируется в коде с остальными как запасными.

### 6.3 Остальные системные экраны

Интенты из п. 4.6. Каждый запуск обёрнут в проверку `resolveActivity`; при отсутствии обработчика показывается короткое сообщение «Недоступно на этом телевизоре».

## 7. Данные погоды

- Прогноз: `https://api.open-meteo.com/v1/forecast` с параметрами `latitude`, `longitude`, `current=temperature_2m,relative_humidity_2m,apparent_temperature,is_day,precipitation,weather_code,pressure_msl,wind_speed_10m,wind_direction_10m`, `hourly=temperature_2m,weather_code,precipitation_probability,is_day`, `daily=weather_code,temperature_2m_max,temperature_2m_min,sunrise,sunset,precipitation_probability_max`, `wind_speed_unit=ms`, `timezone=auto`, `forecast_days=7`.
- Геокодинг: `https://geocoding-api.open-meteo.com/v1/search?name=<строка>&count=8&language=ru&format=json`. Сохраняем `name`, `admin1`, `country`, `latitude`, `longitude`, `timezone`.
- Давление: `pressure_msl` гПа × 0.750062 → мм рт. ст., округление до целого.
- Направление ветра: 16 румбов → 8 русских сокращений (С, СВ, В, ЮВ, Ю, ЮЗ, З, СЗ).
- Коды WMO → русские описания и иконки: 0 ясно; 1 преимущественно ясно; 2 переменная облачность; 3 облачно; 45/48 туман; 51/53/55 морось; 56/57 ледяная морось; 61/63/65 небольшой/умеренный/сильный дождь; 66/67 ледяной дождь; 71/73/75 небольшой/умеренный/сильный снег; 77 снежные зёрна; 80/81/82 ливень; 85/86 снегопад; 95 гроза; 96/99 гроза с градом. Иконки учитывают `is_day` для кодов 0–2.
- Обновление: при появлении главного экрана, если кэшу больше 30 минут; далее каждые 30 минут пока экран виден; при смене города на карточке, если его кэшу больше 30 минут. Все города обновляются одним проходом последовательно.

## 8. Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Нет сети / ошибка API | Показываем кэш с пометкой давности. Если кэша нет: «Нет данных, проверьте сеть». Поиск городов: «Нет связи» |
| Приложение с плитки удалено | Плитка пустая с подписью «Выбрать приложение» |
| Приложение без leanback- и launcher-интента | Не попадает в списки |
| Системный экран недоступен | Сообщение «Недоступно на этом телевизоре», приложение не падает |
| Переключение входа не сработало | Перебор вариантов п. 6.2, в конце запуск Live TV |
| `onTrimMemory` | Сбрасываем предзагруженный следующий кадр фона, кэш баннеров ограничен 32 записями |
| Повреждённый DataStore / кэш | Значения по умолчанию, повреждённый файл кэша удаляется |
| Падение активности | Код защитный; система покажет FallbackHome, пользователь вернёт Google TV командой из п. 6.1 |

## 9. Тестирование и приёмка

Модульные тесты (JUnit, без устройства):

- разбор ответов Open-Meteo (прогноз и геокодинг) из сохранённых JSON;
- таблица кодов WMO: каждый код даёт описание и иконку, день/ночь для 0–2;
- пересчёт гПа → мм рт. ст., направление ветра в румбы;
- логика плиток: замена, сдвиг влево/вправо у краёв, заполнение пустых слотов, изменение количества слотов;
- сериализация настроек туда и обратно;
- выбор следующего кадра фона: перестановка без повторов до полного круга.

Проверка на телевизоре (ADB, скриншоты `exec-out screencap`, нажатия `input keyevent`):

1. Главный экран открывается, фокус на первой плитке, часы и дата верны по локали ru-RU.
2. Навигация D-pad по трём ярусам соответствует п. 4.2, фокус виден.
3. Запуск каждого из пяти стартовых приложений и возврат по Home.
4. Добавление двух городов, листание, подробный экран, удаление.
5. Отключение Wi-Fi: кэш и пометка давности; включение: обновление.
6. Все пять служебных иконок открывают нужные экраны; переключение на HDMI 1 работает хотя бы одним из вариантов п. 6.2.
7. Смена фона с интервалом 1 минута и плавным переходом; `dumpsys meminfo` приложения не растёт за 30 минут более чем на 20 МБ.
8. Назначение домашним экраном, кнопка Home, перезагрузка ТВ: «Полка» остаётся домашним экраном.
9. Откат на Google TV одной командой.

## 10. Сборка и установка

- `./gradlew assembleDebug` для итераций; `adb install -r app/build/outputs/apk/debug/app-debug.apk`.
- Финальная установка: `assembleRelease` с ключом из `keystore/polkatv.jks` (создаётся при первой сборке, в git не попадает, пароль в `keystore/README` только локально).
- `tools/install_tv.sh`: подключение к 192.168.100.2:5555, установка, назначение домашним экраном. `tools/restore_googletv.sh`: откат.

## 11. Вне охвата

Рекомендации контента, «продолжить просмотр», голосовой поиск, виджеты других приложений, несколько профилей, собственная заставка, скачивание новых обоев с серверов Xiaomi, папка с пользовательскими фото (возможное будущее расширение), публикация в Google Play.

## 12. Риски

- Способ переключения HDMI на прошивке Xiaomi подтверждается только на устройстве (п. 6.2).
- Прошивка может возвращать Google TV после перезагрузки (п. 6.1, предусмотрен запасной механизм).
- Compose for TV на 32-битном устройстве с 2.4 ГБ: следим за памятью (п. 9, пункт 7), фоновые кадры только в 1080p.
- Open-Meteo без ключа имеет лимит ~10 000 запросов в сутки на IP; при 6 городах и обновлении раз в 30 минут это менее 300 запросов в сутки.
